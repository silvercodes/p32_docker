## 1. Пользователи

### Основные концепции
*   **UID (User ID)**: Уникальный числовой идентификатор.
    *   `UID 0` — всегда `root` (суперпользователь).
    *   `UID ≥ 1000` — обычные пользователи.
*   **Файл `/etc/passwd`**: Содержит информацию о пользователях.
    *   Формат: `имя:x:UID:GID:комментарий:домашний_каталог:оболочка`
    *   `x` означает, что пароль хранится в `/etc/shadow`.

### Команды управления
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `whoami` | Текущее имя пользователя | `whoami` |
| `id` | UID, GID и группы пользователя | `id vasia` |
| `useradd` | Создание пользователя | `useradd -m -s /bin/bash vasia` |
| `passwd` | Установка/смена пароля | `passwd vasia` |
| `su -` | Переключение пользователя (с загрузкой окружения) | `su - vasia` |
| `exit` | Выход из текущей сессии | `exit` |

**Флаги `useradd`:**
*   `-m` — создать домашний каталог.
*   `-s` — указать оболочку (например, `/bin/bash`).

## 2. Группы

### Основные концепции
*   **Primary Group**: Основная группа пользователя (указывается в `/etc/passwd`). Файлы, создаваемые пользователем, по умолчанию принадлежат этой группе.
*   **Secondary Groups**: Дополнительные группы для доступа к ресурсам.
*   **Файл `/etc/group`**: Содержит информацию о группах.
    *   Формат: `имя_группы:x:GID:список_пользователей`

### Команды управления
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `groupadd` | Создание новой группы | `groupadd developers` |
| `usermod -aG` | Добавление пользователя в группу | `usermod -aG developers vasia` |

> **Важно:** Флаг `-a` (append) добавляет группу к существующим. Без него старые группы будут заменены новыми!

## 3. Права доступа (Permissions)

### Структура прав
Каждый файл имеет три категории пользователей:
1.  **User (u)**: Владелец.
2.  **Group (g)**: Группа владельца.
3.  **Others (o)**: Все остальные.

Три типа действий:
*   **Read (r)**: Чтение.
*   **Write (w)**: Запись.
*   **Execute (x)**: Выполнение.

### Числовое представление (Восьмеричное)
| Права | Бинарно | Число | Смысл |
| :--- | :--- | :--- | :--- |
| `---` | 000 | 0 | Нет доступа |
| `--x` | 001 | 1 | Только выполнение |
| `-w-` | 010 | 2 | Только запись |
| `r--` | 100 | 4 | Только чтение |
| `rwx` | 111 | 7 | Полный доступ |
| `rw-` | 110 | 6 | Чтение и запись |
| `r-x` | 101 | 5 | Чтение и выполнение |



### Команды управления доступом
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `ls -l` | Просмотр прав и владельца | `ls -l file.txt` |
| `chmod` | Изменение прав | `chmod 755 script.sh` |
| `chown` | Смена владельца и/или группы | `chown user:group file.txt` |
| `chgrp` | Смена только группы | `chgrp developers file.txt` |

### Синтаксис `chmod`

**Символьный метод:**
*   `u+x` — добавить выполнение владельцу.
*   `g-w` — убрать запись у группы.
*   `o=r` — установить остальным только чтение.
*   `chmod u=rwx,g=rx,o=r file` — комплексная установка.

**Числовой метод:**
*   `chmod 644 file` — `rw-r--r--`.

## 4. Права на директории

Для директорий права означают другое:

| Право | Значение для директории |
| :--- | :--- |
| **r** (read) | Можно посмотреть список файлов (`ls`). |
| **w** (write) | Можно создавать и удалять файлы внутри. |
| **x** (execute) | Можно войти в директорию (`cd`) и получить доступ к файлам внутри (если знаешь имя). |

**Типичные сценарии:**
*   `r--`: Видно список файлов, но нельзя войти или открыть их.
*   `--x`: Нельзя посмотреть список (`ls` ошибка), но можно открыть файл, если знаешь точное имя ("скрытая" папка).
*   `rwx`: Полный доступ.
